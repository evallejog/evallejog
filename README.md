## 🚀 Sobre mí

¡Hola! 👋 Soy Esteban, estudiante de octavo semestre de Ingeniería de Sistemas en la Universidad Central (Bogotá, Colombia). Me interesa el desarrollo de software, el análisis de datos y los sistemas distribuidos.
